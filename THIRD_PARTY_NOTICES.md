# Third-party notices

The package includes the separate [bliss-guidance-library-signals](https://github.com/chrober/bliss-guidance-library-signals) executable, which depends on [bliss-playlist-guidance-spi](https://github.com/chrober/bliss-playlist-guidance-spi).
[Alternative Play Count](https://github.com/AF-1/lms-alternativeplaycount) is optional and is not included in this package.
The release package contains the native provider's version-specific dependency inventory, license texts and supplemental upstream notices in `third-party-licenses/`. The native source archive is linked from `SOURCE.md` in the package.
